# AI Text Flagger

Estimates whether an English text was written by a person or generated by an AI model. Two independent
detectors score the text: a fine-tuned DistilRoBERTa classifier and the Fast-DetectGPT zero-shot detector
(Qwen2.5-0.5B). When they disagree the verdict is "Uncertain". The result is a probability that supports
human judgement, not proof.

Code, evaluation and limitations: https://github.com/gupta1705/AI-Text-Flagger

Runs on a free CPU, so the first check after the Space wakes up takes a minute while the models load.
